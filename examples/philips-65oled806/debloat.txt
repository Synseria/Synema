# Philips 65OLED806/12 (Europe), Android TV 11, TP Vision (product PH1M_EA_9970A, MediaTek), 2.8 GB RAM.
# TP Vision's own packages use the org.droidtv prefix.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/philips-65oled806/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/philips-65oled806/debloat.txt com.google.android.tvlauncher
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.tvlauncher. Live TV app: org.droidtv.playtv.
# Quirks on this firmware:
# - USB debugging alone opens port 5555 (no wireless pairing needed).
# - Remote app keys are routed by org.droidtv.GlobalKey before apps see them: Rakuten (779) opens
#   tv.wuaki.apptv or its store page, the App Gallery key (326) opens org.droidtv.nettv.market,
#   Blue (186) opens the e-manual. Red/Green/Yellow reach the foreground app.
# - The Freeview UK apps (uk.co.freeview.*) ship disabled on French sets.
# - org.droidtv.nettvregistration shows a terms prompt for the FAST channels (onetrust.IABActivity)
#   again and again, which Back does not close; the shell may not disable that component, and the
#   package also serves the network settings: the launcher sends the prompt away instead (home.json
#   "dismiss").
